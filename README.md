## \ud83d\udee0 Quick Start (5 Minutes)

### Step 1: Download & Extract
1. Download `jamilbd_portfolio.zip`
2. Extract to any folder
3. You'll see 5 files

### Step 2: Test Locally (Optional)
1. Open `index_v2.html` in your browser
2. Make sure everything looks good
3. Test on mobile too

### Step 3: Upload to cPanel
1. Login to your cPanel
2. Go to **Files > File Manager**
3. Open `public_html` folder
4. Delete old `index.html` (if exists)
5. Upload ALL 4 files:
   - `index_v2.html` \u2190 rename to `index.html`
   - `founder_journey.jpg`
   - `sunset_portrait.jpg`
   - `cafe_work.jpg`

### Step 4: Visit Your Site
```
https://jamilbd.me
```

## \ud83d\udd12 SSL Setup

After uploading, enable HTTPS:
1. cPanel \u2192 **Security > SSL/TLS**
2. Click **Manage SSL Sites**
3. Select `jamilbd.me`
4. Click **Run AutoSSL**
5. Wait 5 minutes

Now your site will be: `https://jamilbd.me`
